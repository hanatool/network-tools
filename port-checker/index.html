About This Tool

This online port checker helps you verify whether a specific TCP port is accessible from the internet. It is useful for testing web servers, game servers, VPS configurations, routers, firewalls, and custom applications.

Simply enter a hostname or IP address along with the desired port number, then run the check instantly using this responsive and lightweight networking utility.
